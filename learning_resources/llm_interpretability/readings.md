# LLM Interpretability
*About this page*: This page provides a list of academic and other research papers on interpretability of large language model activations, e.g. tracing where knowledge representations are stored in the neural network and what behavior is associated with activating these locations, for example, by quering the model with an input containing data that represents the type of knowledge stored by a particular neuron.
